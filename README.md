# MSAI-631 Hello World

Week 1 development environment exercise for MSAI-631 (AI for Human-Computer Interaction), University of the Cumberlands.

A minimal Gradio app deployed as a Hugging Face Space and mirrored to GitHub. It will be extended into the Week 3 chatbot.

## Links
- GitHub repository: https://github.com/oyinakpe2-firstgrandprince/msai631-hello-world
- Hugging Face Space: https://huggingface.co/spaces/oyinakpe2/msai631-hello-world

## Run locally
```
pip install -r requirements.txt
python app.py
```
